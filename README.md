# Вебсистема аптечного складу та обліку медикаментів (Django + MySQL)

Проєкт розроблено на основі міграції десктопного додатку (Flet) у сучасну реляційну вебсистему на базі **Django 6** та СУБД **MySQL 8.0**.

---

## 🚀 Швидкий запуск проєкту

### 1. Віртуальне середовище і залежності
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Налаштування підключення до MySQL
У корені проєкту знаходиться файл `.env`. Відкрийте його та вкажіть ваш пароль до MySQL:
```env
DB_ENGINE=mysql
DB_NAME=pharmacy_db
DB_USER=root
DB_PASSWORD=ваш_пароль_до_mysql
DB_HOST=127.0.0.1
DB_PORT=3306
```
> Потрібен запущений **MySQL 8.0+** (або сумісна MariaDB). SQLite не використовується. Скопіюйте `.env.example` у `.env` і заповніть усі значення, зокрема `SECRET_KEY`.

### 3. Автоматична ініціалізація бази даних та наповнення даними
Виконайте команду:
```bash
python manage.py migrate
python manage.py seed_data
```
Або для автоматичного створення бази у MySQL разом із паролем:
```bash
python manage.py setup_mysql --password=ваш_пароль
```

### 4. Запуск локального вебсервера
```bash
python manage.py runserver
```
Після запуску відкрийте браузер за адресою: [http://localhost:8000/](http://localhost:8000/)

## Додаткові можливості для перевірки

- Реєстрація: `/register/`.
- CRUD препаратів: `/products/` (список із пошуком і пагінацією).
- Категорії: `/categories/`.
- Власник препарату встановлюється сервером під час створення; редагувати й видаляти його може лише власник.

## 🗄️ Структура бази даних та зв'язки (ERD)

У реляційній моделі реалізовано повноцінні зв'язки між сутностями:
1. `Category` (Категорія) $\xrightarrow{\text{1:N}}$ `Medicine` (Медикамент)
2. `Medicine` $\xrightarrow{\text{1:N}}$ `StockBatch` (Партія на складі з терміном придатності)
3. `User` $\xrightarrow{\text{1:1}}$ `UserProfile` (Ролі: admin / pharmacist)
4. `User` $\xrightarrow{\text{1:N}}$ `Sale` (Чеки продажів)
5. `Sale` $\xrightarrow{\text{1:N}}$ `SaleItem` (Позиції в чеку) $\xleftarrow{\text{N:1}}$ `Medicine`
6. `Medicine` $\xrightarrow{\text{1:N}}$ `StockMovement` (Журнал руху товару: прихід / продаж / повернення / списання)

Всі готові SQL-скрипти знаходяться в папці `database/`:
- `database/schema.sql` — DDL створення таблиць, зовнішніх ключів та індексів.
- `database/seed_data.sql` — DML заповнення початковими даними.
